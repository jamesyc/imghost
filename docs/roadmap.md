# Roadmap

This file is intentionally forward-looking and separate from current-state docs.

## Near-term candidates

- richer deployment and operations documentation
- stronger guidance around bootstrap-only vs rotatable secrets
- more polished end-user and admin UI
- decide whether trusted-proxy enforcement should eventually become the default
- broader backup and restore runbooks

## Product and identity work

- more provider support beyond Google OAuth
- richer multi-provider account management
- private or password-protected albums
- password reset flows

## Operations and platform work

- richer production reverse-proxy guidance
- external telemetry aggregation or dashboards beyond the in-process Prometheus endpoint
- more explicit deployment migration guidance for Garage/Postgres secret rotation
